# nixos-installer

Терминальный установщик NixOS и редактор конфигурации модулей для Linux и macOS. Интерфейс на Rust использует [terminalib](https://github.com/acup1/terminalib).

## Запуск

Скачайте из [GitHub Releases](https://github.com/acup1/nixos-installer/releases) файл для своей системы, проверьте его по `SHA256SUMS` и выдайте право на запуск. Команда `nixos-installer configure` открывает редактор конфигурации. На Linux команда `sudo nixos-installer install` открывает мастер установки. Управлять можно клавиатурой и мышью. Tab и стрелки перемещают фокус, Space выбирает модуль, Enter открывает редактор, Ctrl+N и Ctrl+P переключают шаги.

## Настройка системы

1. Редактор открывает `~/.config/config.nix` и берёт путь к flake хоста из поля `flakeDir`. На странице источников можно сменить селектор, задать другой flake или явно выбрать конфигурацию через `путь#имя`. Добавьте доверенные Git-репозитории с модулями и выберите для них ветку, тег или коммит.
2. Локальный режим читает рабочую копию или скачивает репозиторий. Закреплённый режим записывает в конфигурацию удалённый URL и точную ревизию Git. При локальной установке в новую систему мастер копирует выбранную ревизию на целевой диск.
3. Обновите каталог, выберите компоненты и откройте параметры. Они берутся из `module.json` каждого компонента. В списках пакетов используются имена атрибутов nixpkgs, например `ripgrep` или `kdePackages.kate`.
4. Проверьте выбор. Команда **Save** сохраняет селектор. При первом изменении установщик сохраняет исходный файл рядом. Одно нажатие **Rebuild** сохраняет выбор и запускает `nh os switch` или `nh darwin switch` с именем конфигурации из выходов flake. Если хост применяет Home Manager отдельно от системы, домашняя конфигурация активируется отдельно.

Для перестройки нужны Git, Nix с включёнными flakes, `nh` и доступ к записи в выбранный селектор. Описание интерфейса репозиториев доступно в [JSON Schema](schema/module.schema.json). Пакеты и настройки выбранного репозитория будут исполняться Nix с полномочиями, необходимыми для сборки и активации системы.

## Установка NixOS

Запускайте мастер из Linux live-системы с инструментами NixOS. Выберите локаль, часовой пояс, раскладку, сеть, имя компьютера, пользователя и рабочий стол. Мастер поддерживает очистку выбранного диска, установку в выбранный раздел с сохранением соседних разделов и установку в заранее смонтированное дерево. Режим **Install alongside** на диске GPT с UEFI находит свободный диапазон и показывает, какие разделы в нём появятся. Можно выбрать существующий EFI-раздел или создать новый. Для других схем доступна ручная разметка через `cfdisk`.

Поддерживаются UEFI с systemd-boot, BIOS с GRUB, ext4, Btrfs, XFS, LUKS и файл подкачки. Перед записью мастер показывает устройства и список операций, запрашивает подтверждение и повторно проверяет целевые устройства. Пароли вводятся в терминале при запросе `cryptsetup` или `passwd`. Установщик создаёт конфигурацию оборудования и flake в `/etc/nixos`, затем вызывает `nixos-install`.

Для ручной разметки требуется `cfdisk`. Для автоматической установки нужны инструменты NixOS, util-linux и утилиты выбранных файловых систем. Если live-образ содержит графический Calamares, мастер также позволяет запустить его со штатными модулями этого образа. Выбор, сделанный в TUI, применяется к нативной установке NixOS.

## Разработка и выпуск

```sh
cargo test --locked
cargo run --locked -- configure
```

CI проверяет и собирает релизные бинарники для x86-64 и ARM64 под Linux и macOS. Linux-бинарники собираются с musl. Тег вида `v0.1.0` должен совпадать с версией в `Cargo.toml`. После успешных сборок CI публикует четыре файла и `SHA256SUMS` в GitHub Release.
